# Roadmap

## Near Term

- Add Linux and macOS bootstrap coverage.
- Produce machine-readable bootstrap output for automation.
- Expand rule-health checks for contradictory approval and completion rules.
- Add proposal lifecycle examples: proposed, accepted, rejected, and retired.

## Later

- Define adapters for additional coding-agent Skill layouts.
- Compare fixed routing cases across agent and model versions.
- Add an opt-in migration planner for existing instruction repositories.

The project will not add automatic rule promotion. Human review remains part of
the active-instruction boundary.
